# Инструкция по использованию Google Antigravity Client

Этот клиент (версия `1.0.22`) предназначен для перенаправления трафика Antigravity через защищенный прокси-сервер и автоматического обхода региональных ограничений.

## 1. Компоненты на виртуальной машине
На виртуальной машине macOS установлены и настроены следующие компоненты:
*   **Antigravity 2.0 (Hub)**: Версия `2.2.1` (установлена в `/Applications/Antigravity.app`).
*   **Antigravity IDE**: Версия `2.1.1` (установлена в `/Applications/Antigravity IDE.app`).
*   **Antigravity CLI (agy)**: Версия `1.0.15` (установлен в `/Users/user/.local/bin/agy`, путь прописан в `~/.profile`).

---

## 2. Запуск Клиента в режиме разработки
Клиент работает на базе Tauri (Rust + React). Для его запуска:

1.  Откройте **Терминал** на рабочем столе macOS виртуалки (не через удаленный SSH).
2.  Перейдите в директорию проекта:
    ```bash
    cd ~/projects/Client
    ```
3.  Запустите команду запуска разработчика:
    ```bash
    export PATH="/usr/local/bin:/Users/user/.cargo/bin:$PATH"
    npm run tauri dev
    ```
    *Примечание: Если запускать клиент через удаленный SSH, macOS заблокирует доступ к связке ключей (Keychain), что вызовет ошибку инжекции токенов в IDE.*

---

## 3. Подключение и работа с прокси
1.  После запуска клиента откроется графическое окно **Antigravity Client**.
2.  Выполните вход (Logout / Login), чтобы получить активный токен.
3.  В блоке **Ready to Code?**:
    *   Выберите **`v2.0`**, если вы хотите работать в приложении Antigravity 2.0.
    *   Выберите **`IDE`**, если вы хотите работать в Antigravity IDE.
4.  Нажмите кнопку активации (сделать статус **`ACTIVE`**).
5.  Клиент автоматически запустит локальный прокси на порту `8047` и пропишет настройки прокси (`proxyBaseUrl`) в файлы конфигурации IDE/2.0.
6.  В процессе работы в терминале клиента будут отображаться логи запросов проксирования (например, перенаправление `/v1internal/loadCodeAssist` с автоматической подменой региона на `US`).

---

## 4. Разрешение экрана и управление
*   Разрешение экрана виртуальной машины настроено на комфортное **1280x800**.
*   Вы можете изменить разрешение в любой момент из терминала командой:
    ```bash
    "/Library/Application Support/VMware Tools/vmware-resolutionSet" <ширина> <высота>
    ```
